# Visual verification, 2026-11-14: Stylix themes

The five visual scenarios of the [Stylix specification](../../specifications/5-STYLIX-INTEGRATION.md) §14, run with `scripts/ui/stylix-themes.sh` and reviewed from its screenshots by Claude (the coding agent). **The maintainer has not reviewed these screenshots yet.**

| | |
|---|---|
| Environment | Headless Sway in the UI test sandbox (`scripts/ui-session.sh`), GTK's default Adwaita light look, no desktop GTK theme |
| Themes | Generated by the real Home Manager module with Stylix: `nix build ./nix/tests#stylix-themes` (`nix/tests/visual.nix`) |
| Launch | Through a wrapper passing `--theme-file`, as the module's does |
| Commit | Branch `docs-stylix-guide`, based on `0a5fb9d` |

Each scenario was shown at launch (Home selected in the navigation pane) and with three panels open (Home → Documents → Notes) and files selected in Visual Mode.

## Reproduce

```sh
nix build ./nix/tests#stylix-themes -o /tmp/stylix-themes
STYLIX_THEMES=/tmp/stylix-themes nix develop -c scripts/ui-session.sh scripts/ui/stylix-themes.sh /tmp/stylix-shots
```

The script's automatic checks (each theme passes `seshat --check-theme`, Seshat starts with it, no errors in the log) passed for all five.

## Results

| Scenario | Scheme and settings | Result |
|---|---|---|
| Dark | Gruvbox Dark Hard, polarity dark | ✅ Readable. Panels, connectors and the active panel's accent outline are clear; selected files (accent at 30%) stand out; the selected navigation item shows its 12px outline and accent icon on the shared background |
| Light | Gruvbox Light Hard, polarity light | ✅ Readable, the same structure as dark. Muted text was faint with base03 and is readable with base04 (finding 1) |
| Strong accent | Outrun Dark, polarity either | ✅ The vivid blue accent marks selection, the active panel and connectors without overpowering the text. Muted text was very faint with base03 and is readable with base04 (finding 1) |
| Custom fonts | Gruvbox Dark Hard, sans-serif DejaVu Serif, 14 pt | ✅ DejaVu Serif at 14 pt everywhere in Seshat; rows grow to fit |
| User overrides | Gruvbox Dark Hard with `accent` and `focus` `#ff5555` and `navigation_selected` `#3c3836` | ✅ The red accent and focus replace Stylix's; the selected navigation item has its own colour with the 12px corners; everything else still comes from Stylix |

Across all five, the spatial layout reads the same in light and dark. Error, warning and success messages did not appear in these screenshots; their colours (base08, base09, base0B) are checked by the Nix checks, not visually.

## Findings

1. **Muted text was faint, fixed the same day.** With `text_muted` = base03 (Base16's comment colour), file types and dates were faint, most of all on Outrun Dark and Gruvbox Light. The mapping now uses base04 for muted text and base05 for secondary text (decision S9); the five scenarios were run again with it, and muted text is readable in all of them while staying visibly quieter than file names.
2. **The header bar is not themed by Seshat.** The path bar's text uses Seshat's colours but sits on GTK's header bar, which in this session has GTK's default light look; with the dark themes, the path is hard to read there. On a desktop where Stylix also themes GTK (its GTK target, on by default) the header bar follows the same scheme. Already recorded as a known gap (the same happens with Seshat's built-in dark theme).
3. **Not covered:** hover, keyboard focus on single widgets, and error, warning and success messages were not captured; the screenshots show static states. In the overrides scenario the red `focus`/`accent` appears on the active panel's outline.
